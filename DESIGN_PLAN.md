## Суть стиля

Светлый минимализм «как технический паспорт»: без рамок-карточек и теней,
максимум воздуха, KPI разделены **вертикальными волосяными линиями**,
заголовки секций — с жирной чёрной чертой снизу. Цифры — крупные тонкие,
моноширинные (tabular-nums). Акцент проекта (синий #1565C0 + амбер #F5A623)
сохраняется на активной вкладке и заголовке.

## ВАЖНО — отличия от текущего UI (что переделать)

1. **Убрать карточки** `st.container(border=True)` с синей полосой сверху
   (введено в v0.10.14) → перейти на «секции без рамок» с чертой-разделителем
   под заголовком. Это инверсия текущего CSS в `ui/app.py`.
2. **Кнопки** — сейчас скруглённые с серой рамкой (v0.10.3/0.10.15) →
   сделать прямоугольными (border-radius 0), чёрный контур / чёрная заливка
   для primary. Амбер можно оставить для primary-варианта (на выбор).
3. **KPI-ряды** — сейчас `st.columns(4)` + `st.metric`. Для вертикальных
   волосяных линий между ячейками: либо CSS `border-right` на
   `[data-testid="stColumn"]` внутри KPI-блока (через :has-маркер, как уже
   делаем для колонок «Параметры»), либо рендер KPI-ряда单 одним
   `st.markdown` с собственной HTML-сеткой. **Это главная сложность.**
4. **Баланс территории — НЕ менять:** оставить существующий **treemap**
   (v0.9.26), а не столбчатую диаграмму из макета. В макете показаны бары
   только для наглядности — в проде остаётся дерево-treemap.

## Карта «макет → код»

| Блок макета | Где в коде |
|---|---|
| Глобальный CSS (фон, H1, кнопки, секции) | `src/urban_model/ui/app.py` (блок `<style>`), bump CSS-маркера |
| Заголовки секций H2 с чертой | CSS для `div[data-testid="stVerticalBlockBorderWrapper"] h5` + убрать border карточек |
| KPI-сетка с линиями | `src/urban_model/ui/output.py` → `render_kpi` (ряды `st.columns(4)`) |
| Кнопки (прямоугольные) | `app.py` CSS `stButton/stDownloadButton` |
| Баланс (treemap) | `output.py` — **оставить как есть** |
| Карточки рекомендаций | `src/urban_model/ui/optimizer.py` `_render_kpi_block` (уже на st.dataframe) |

## Порядок реализации (когда вернёмся)

1. `app.py`: заменить CSS карточек/кнопок/заголовков на токены M3 + bump маркера.
2. Прогнать визуально все вкладки (Расчёт / Параметры / Оптимизация / Сравнение).
3. Точечно поправить KPI-сетку под вертикальные линии (output.py).
4. Проверить, что treemap, altair-графики и таблицы читаются на белом фоне.
5. Тесты (UI не покрыт тестами — проверка ручная), затем commit + push.

**Точка отката перед редизайном:** последний коммит до правок UI.
